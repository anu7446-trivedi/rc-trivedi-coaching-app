📲 Android App डाउनलोड करें

केवल Android फोन के लिए · जल्द ही Google Play Store पर भी

Install कैसे करें

  1. ऊपर का बटन दबाएँ → फाइल डाउनलोड होगी।
  2. डाउनलोड पूरा होने पर फाइल खोलें → Install दबाएँ।
  3. फोन पूछे "इस स्रोत से ऐप इंस्टॉल करें?" → Settings → Allow करें, फिर वापस आकर Install।
  4. "Play Protect" चेतावनी आए → Install anyway / फिर भी इंस्टॉल करें दबाएँ। (यह हमारा अपना ऐप है।)
  5. ऐप खोलें → मोबाइल नंबर + OTP से लॉगिन करें।
